VeydriftAgent Skills

Two skills — one plans the move, the other signs it

A pair of Claude Code skills for playing Veydrift semi‑autonomously. The agent reads your planet and proposes a single next action per tick; the wallet engine is the only thing that ever builds calldata or signs, and never without an explicit --confirm. Tiered trust, guardrails on both layers, your planet stays on your own key.

One config file

policy.json sets the tier, which action types are unlocked (building, research, combat, alliance, ACS‑defense…), your build/research priorities, and hard spend limits — the agent and the wallet each read it independently, so nothing runs that your policy didn't allow.
