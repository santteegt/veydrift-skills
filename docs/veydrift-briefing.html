1. The game in one screen

You own a planet. Mines produce Metal, Crystal and Deuterium every hour. You spend those on buildings, research, ships and defenses. Ships fly missions to other coordinates to raid, transport, harvest debris or colonize. Every meaningful action is a Base transaction — there is no off-chain game server that owns your state.

The three loops

LoopCadenceWhat it is
EconomyHoursMain build queue — one job at a time per body. Mines → energy → Robotics → Lab/Shipyard.
ResearchHours–daysSeparate queue, one per player (not per planet). Levels apply to every planet you own.
FleetMinutes–hoursMissions. Limited by fleet slots (Computer Technology), fuel, and cargo.

These run in parallel. A well-managed planet always has all three occupied — that is exactly the kind of bookkeeping you hand to an agent.

Rules that bite beginners

  • Fuel comes out of cargo. available cargo = total ship cargo − mission fuel. Load a raid to 100% and it launches with zero loot capacity.
  • Energy is not a resource you hold. If produced < required, every mine is scaled down by produced/required. Under-powered mines are the #1 early mistake.
  • Confirmed ≠ indexed. The wallet receipt can land before the backend index catches up. Never chain a dependent action off a displayed balance that hasn't been re-indexed.
  • Score protection. Under 50,000 score you can only fight within a 1.5× score gap. 50k–499,999 → 10×. 500k+ → no score gate. A 24h bashing window also caps repeat hits on the same target.
  • Stuck missions. If a mission sits in Resolving for 60s, a permissionless Resolve button appears — anyone can push it. Awaiting randomness is different and must wait.

Suggested first 48 hours

  1. Metal Mine → 4, Crystal Mine → 3, interleaved with Solar Plant → 4. Never let energy go negative.
  2. Deuterium Synthesizer → 3–4 early (unusual advice, justified by the 1.502× bonus here) and push Solar to 6–7 to carry it.
  3. Robotics Factory 2 — it divides every later build time, so it pays for itself fast.
  4. Research Lab 1 → Energy Technology 1 → Combustion Drive 1–2 → Computer Technology 1 (fleet slots).
  5. Shipyard 2 → a handful of Small Cargos. Cargo, not fighters: early value comes from moving resources and looting undefended inactives, not from combat.
  6. A couple of Rocket Launchers so you aren't a free farm.

The docs publish cost = base × factorlevel but never the per-building factor. You don't need it — GET /wallet/{addr}/infrastructure returns the live cost at your current level for every building. Same for research and ships.

3. Plugging in an agent

Veydrift is unusually agent-friendly: public on-chain state, a free read API, and no anti-bot layer. There is no official Veydrift MCP server or bot API — you build the integration yourself out of three pieces. The read layer is richer than the docs suggest, so the ABI is only needed to write.

1
Read — HTTP APIFree, no key, no auth. Beyond the documented routes there are four undocumented ones that carry the real payload: /wallet/:addr/infrastructure (building levels, live costs, energy balance, production/hr, storage caps, raidable resources), /research, /shipyard (incl. fleet slots) and /missions. An agent can plan the entire economy from these alone.
2
Verify — Base RPCOptional for planning, since the API returns live costs. Still worth an eth_call before large or irreversible spends, and for anything the API doesn't expose (defenses, battle reports). Compare latestIndexedBlock against the chain head to detect lag.
3
Write — signed transactionsThe agent holds a key and calls the game proxy 0xf397910F005151b09644228573a4353818D3755d. Wait for the receipt, then poll until the index reflects it, before issuing any dependent action.

The loop the agent should run

every 10 minutes:
  health = GET /health          # gate on ok===true && readiness.ready===true
                                # nulls in chainSync/indexer are NOT errors — see below
  infra  = GET /wallet/<addr>/infrastructure   # levels, live costs, energyBalance
  tech   = GET /wallet/<addr>/research
  yard   = GET /wallet/<addr>/shipyard

  if building queue empty     -> next build, only if produced >= required energy
  if research queue empty     -> next research
  if mission "Resolving" 60s+ -> submit permissionless resolve

  for each submitted tx:
     await receipt -> poll index until state changes -> only then continue
Gotcha that will stop a naive agent dead. The backend runs a worker pool where only worker 0 does chain sync; reads land on replicas. So /health legitimately returns null for chainSync, indexer, rpc and most of readiness. Those nulls are not an outage — gate on ok and readiness.ready only. Richer telemetry lives in the indexer block on the wallet routes. Likewise, lastReconciledBlock trails latestIndexedBlock by over 1.5M blocks by design; full reconciliation is a manual operator job. Judge freshness by indexedState: "healthy", not by that gap.

Autonomy tiers — pick deliberately

TierAgent doesRisk
AdvisorReads only, tells you what to click.None. Good first week.
Economy botSigns builds and research only. Never launches fleets.Low — worst case it wastes resources on your own planet.
Full operatorAlso launches raids, transports, harvests.Real. A bad raid loses your fleet; a bad target trips bashing rules.
A fully autonomous signer means a hot private key on a machine. Use a dedicated burner wallet that holds the planet and nothing else, funded with a small amount of ETH for gas. Never give an agent the key to a wallet holding assets you care about — and note that on Veydrift the burner is the account, so treat losing it as losing the planet.

4. What the agent cannot do for you

  • Judge diplomacy. Alliances, ACS, and who not to poke are social calls.
  • Absorb combat variance. Rapidfire is a per-shot continue-chance chain, not a guaranteed multiplier — an agent that treats factor R as "R shots" will consistently over-estimate its own attacks.
  • Beat the index. If the backend is lagging, the correct behaviour is to wait, not to act on a stale balance.
  • Trust the docs blindly. They omit a whole ship (Pathfinder, id 14), call the Dreadstar a "Deathstar" in the rapidfire tables, and describe a Base Sepolia deployment in the README while the live game is on mainnet. Verify against /runtime-config and the live catalogs.

Verified constants worth pinning: universe speed = 1 (so every duration formula in the docs works as written), base fleet slots = 1, base storage cap = 10,000 per resource. Full ID maps for buildings, technologies and ships are in NOTES.md.
